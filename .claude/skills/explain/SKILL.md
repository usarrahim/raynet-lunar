Explain "$ARGUMENTS" to the owner. Do not change any file.

- Language: simple Turkish. The first time a technical term appears, give the English term in
  parentheses, for example "maskeli kayıp (masked loss)".
- Structure:
  1. One-sentence summary.
  2. Why this project needs it.
  3. How it works, step by step, pointing to the real functions and line numbers.
  4. A tiny numeric example if possible (for example a 4×4 map).
  5. Two questions the instructor may ask, with short answers.
